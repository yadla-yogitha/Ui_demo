# Color System (Strict)

This prototype uses exactly 4 primary colors for brand-facing UI, plus a very limited standard set for neutral UI structure.

## 1) Core Colors (Only 4)

- `Primary`: `#E8E109`
- `Secondary`: `#0C1C5C`
- `Tertiary`: `#0D0E0E`
- `Text`: `#0C1C5C`

## 2) Standard Colors (Limited)

- `Surface`: `#FFFFFF`
- `Border/Line`: `#D6DEEA`

## 3) Usage Rules

- Brand areas, key actions, emphasis, status, and text should use only the 4 primary colors.
- Standard colors are only for neutral surfaces and borders.
- Do not introduce extra text colors or extra accent colors unless approved.
- Keep color mapping consistent across all screens.
